# pi-transcript

**模型可以压缩上下文，但你应该仍然能看到自己问过什么。**

给 Pi 加一个可搜索的聊天记录阅读器：找回压缩前已保存的提问和回答，收起阅读器里的工具输出，随时确认自己刚才问了什么。

**它是单独打开的阅读窗口，不会改变主聊天区的滚动方式，也不会改变模型的记忆。**

[English](README.md) · [架构](docs/architecture.md) · [安全边界](SECURITY.md)

## 三步开始使用

已经在使用 Pi？按下面三步安装即可。插件复用 Pi 自带的组件，**不需要另外安装运行库**。[支持哪些版本？](#兼容性与验证)

### 1. 在终端安装

在终端执行，不是在 Pi 的聊天输入框里执行：

```bash
pi install git:github.com/FelixFoster/pi-transcript@v0.1.0
```

### 2. 回到 Pi，加载插件

在 Pi 的聊天输入框里输入：

```text
/reload
```

**`/reload` 是 Pi 自带的重载命令，不是本插件提供的。** 也可以退出并重新启动 Pi，让插件在启动时加载。

### 3. 打开历史记录

在 Pi 中输入：

```text
/transcript
```

按 **Esc 或 q** 关闭阅读器，回到聊天界面。搜索编辑状态下，先按 Esc 退出搜索编辑，再按一次关闭。

## 主要功能

- **找旧问题和回答**：查看当前分支中压缩前仍保存在会话里的原文。
- **按关键词查找**：例如输入 `/transcript 安装`，搜索也覆盖折叠的工具输出和思考。
- **只看自己问过什么**：打开阅读器后按 `u`，只显示用户提问。
- **减少阅读干扰**：阅读器里的工具输出和思考默认收起，按 Enter 展开；主聊天区不受影响。
- **保留最近问题的预览**：主界面输入框上方显示最近提问的一行预览，可以关闭。

## 阅读器内操作

- 默认定位到最近一次提问，Home 回到当前分支的开头。
- ↑↓ / j、k：切换条目；PgUp/PgDn：翻页阅读长消息。
- Enter / 空格：折叠或展开当前条目。
- `/` 或 Ctrl+F：搜索；Enter 应用，Esc 取消编辑。
- 搜索覆盖折叠的工具输出和思考，按 n/N 切换匹配条目。
- `u`：只看用户提问；`c`：清除搜索；Esc / q：退出。
- 全屏模式下，宿主支持时可用滚轮和点击；普通终端模式使用键盘导航。

也可用 `Ctrl+Shift+H` 打开阅读器。若终端拦截快捷键，使用 `/transcript` 即可。

搜索是忽略大小写的字面量匹配，不是正则。匹配结果按条目过滤，匹配的活动自动展开；长条目尝试跳到首个完整落在换行后单行内的匹配，其他位置继续翻页查看，不提供逐个匹配位置跳转。

## 关闭、隐藏或停用

| 想做什么 | 怎么操作 |
| --- | --- |
| 关闭阅读器，继续聊天 | 在阅读器中按 **Esc 或 q**；搜索编辑状态下先按 Esc 退出编辑 |
| 隐藏最近问题的预览 | 回到 Pi，输入 `/transcript-pin`；再次输入可恢复 |
| 停用插件，但保留安装 | 在终端运行 `pi config`，取消勾选该扩展，再回 Pi 执行 `/reload` |
| 完全移除插件 | 见下方[卸载](#卸载) |

这些操作都不会删除聊天记录。`/transcript-pin` 的开关在重载或切换会话后会重置。如需在一次运行中默认关闭预览，在终端用 `pi --transcript-no-pin` 启动 Pi。

## 明确边界

**这是独立阅读器，不是主聊天区的无缝无限回滚补丁。**

- 不修改 Pi 内部方法、模型上下文或主聊天区的渲染方式。
- 不关闭压缩，不降低 token 消耗，也不让模型重新获得所有历史。
- 不复制消息到会话，不修改 JSONL，不上传数据，不写额外历史库。
- 只显示当前分支。查看其他分支请先用 Pi 的 `/tree` 切换。
- 内容以纯文本显示；图片用占位符，隐藏的扩展消息和内部状态不展示。
- 原工具已经截断、会话已删除、导入时缺失的内容无法恢复。
- 阅读器是打开时的快照；继续执行产生的新内容需要关闭后重新打开。
- 虚拟视口只对当前可见/访问的条目换行，缓存最多 32 个条目；读取投影和搜索仍随文本量线性增长，不是无限内存方案。

## 兼容性与验证

- **Pi**：已验证 0.85.1 和 1.5.0，普通模式与全屏模式均通过测试。
- **Node.js**：需要 22.19 或更高版本；测试覆盖 Node.js 22 和 24。
- **发行包**：上述测试使用 `@earendil-works/pi-coding-agent`。其他版本、发行包或分叉版本尚未验证，不能保证兼容。

`@earendil-works` 只是 Pi 的 npm 包名中的发布者前缀，**不是要另外安装的软件或注册的服务**。插件复用 Pi 提供的界面组件，不会另装一份 Pi。

插件目前通过上面的 GitHub 命令安装，尚未发布到 npm。开发者如需了解依赖声明和实现方式，请看 [package.json](package.json) 和[架构说明](docs/architecture.md)。

包含真实 SessionManager、真实压缩完成 UI 处理函数的回归测试，以及 regular / fullscreen 两种模式下的真实 CLI 伪终端测试。伪终端使用隔离 HOME、合成对话、离线启动，不读取真实会话，也不调用模型。它不等同于真实服务商调用下的端到端压缩验证。

```bash
npm ci --ignore-scripts
npm run check
python3 tests/pty_smoke.py
```

## 卸载

```bash
pi remove git:github.com/FelixFoster/pi-transcript
```

上面的命令在终端执行。然后回到 Pi 输入 `/reload`，或重启 Pi。预览和插件状态会被清理，聊天记录不变。临时使用 `-e` 加载时，请重启并去掉该参数。
